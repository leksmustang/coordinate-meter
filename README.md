# Координатный измеритель

[English version](./README_EN.md)

Приложение для расчёта расстояний между местами съёмки фотографий. Поддерживаются JPEG и PNG. Координаты, высота, заявленная GPS-точность и время читаются из EXIF либо локально распознаются с подписи NoteCam. Фотографии не отправляются в интернет.

## Запуск готового приложения

Откройте двойным щелчком `Готовые приложения/Windows/Координатный измеритель 1.5.11.exe`. Установка, Node.js и PowerShell не требуются. Все необходимые компоненты, включая русско-английскую OCR-модель и библиотеку карты, уже находятся внутри приложения.

Приложение переносимое: EXE можно скопировать в другую папку или на другой компьютер с 64-битной Windows. Фотографии обрабатываются локально и не отправляются в интернет.

Для передачи другому человеку отправьте архив `Готовые приложения/Windows/Координатный измеритель 1.5.11 — Windows.zip`. Получателю достаточно распаковать архив в обычную папку и открыть EXE; классическая установка не требуется. Поскольку файл пока не подписан коммерческим сертификатом, Windows SmartScreen может показать предупреждение о неизвестном издателе.

### Android

Файл `Готовые приложения/Android/Координатный измеритель 1.5.10.apk` можно скопировать на телефон и открыть через файловый менеджер. Android попросит разрешить установку приложений из этого источника. APK подписан тестовым ключом разработчика, поэтому магазин Google Play для распространения не используется. Режим камеры с GPS пока не добавлен.

Мобильная версия выбирает несколько JPEG или PNG из галереи, локально читает EXIF и подписи на фотографиях, считает расстояния, открывает выбранную точку в Яндекс Картах и передаёт CSV через стандартное меню Android. Для OCR и расчётов интернет не нужен; интернет используется только картой и поиском объектов.

1. Добавьте две или несколько фотографий JPEG или PNG.
2. Приложение сначала проверит EXIF. Если координат там нет, оно локально распознает подпись NoteCam в нижней части снимка или компактную GPS-плашку WGS84 в верхней части. Если быстрые зоны не дали результата, приложение ищет пару координат по всему кадру, включая цветные надписи без подписей и разделителей.
3. Обязательно сверьте значения со снимком: точка с пометкой `OCR — проверьте` требует человеческого подтверждения. Для исправления нажмите `✎`.
4. При необходимости измените порядок точек стрелками или кнопкой «По времени».
5. Смотрите расстояние по всему маршруту либо выберите конкретные точки A и B.
6. Кнопка «Экспорт CSV» сохраняет таблицу, совместимую с русской локалью Excel.

### Дополнительно в Windows 1.5.11

- Кнопка `▣` у любой фотографии открывает выбор области. Выделите надпись с координатами, нажмите «Распознать область», сверьте найденные варианты с фото и примените нужный. Поля широты и долготы можно исправить перед применением.
- Блок «Расстояния между всеми точками» проверяет каждую уникальную пару с координатами, включая несоседние точки. Список отсортирован от ближайших к самым дальним; фильтр показывает пары ближе 25 м или все пары. Кнопка «Измерить» выбирает пару, «На карте» загружает карту по явному нажатию и показывает её расположение.

## Карта и ближайшие объекты

После распознавания координат выберите исходную точку. Кнопка «Открыть в Яндекс Картах» без API-ключа откроет обычный сайт Яндекс Карт в браузере с выбранной координатой: район можно осмотреть вручную, приблизить карту и воспользоваться обычным поиском Яндекса. Координаты одновременно копируются в буфер обмена — их можно вставить в поиск, если сайт не установил метку автоматически.

Кнопка «Загрузить карту и объекты» показывает маршрут на подложке Яндекс Карт и автоматически ищет ближайшие объекты выбранных типов: полиция, МВД, ФСБ, детские площадки, детские сады и школы.

После загрузки карты можно нажать в любом месте, чтобы поставить синюю произвольную точку. Приложение покажет её координаты, расстояние по прямой и азимут от точки маршрута, выбранной в списке «Считать расстояния от точки». Маркер можно перетаскивать; кнопка «Убрать точку» удаляет его.

Оба режима карты работают через интернет. Координаты передаются выбранному картографическому сервису только после нажатия соответствующей кнопки; фотографии остаются на устройстве. Подложка загружается через Яндекс Tiles API, а сведения о ближайших объектах — через OpenStreetMap/Overpass. В автоматическом режиме расстояние до объекта считается по прямой, а не по дорогам. Наличие и названия объектов зависят от полноты и актуальности OpenStreetMap, поэтому результат следует воспринимать как справочный.

Ключи Яндекс Tiles API не вводятся сотрудниками и не показываются в интерфейсе. Для Windows и Android используются разные ключи с обязательной временной подписью запросов. Исходные секреты хранятся локально в `.secrets/yandex-tiles.json`, исключены из Git и во время сборки помещаются только в платформенную часть приложения. Каждое устройство ограничено восемью запросами тайлов в секунду. Windows также отклоняет обращения к своему локальному API не из собственного окна приложения. Без собственного сервера извлечение секрета из распространяемого приложения теоретически возможно, поэтому при подозрении на утечку соответствующий платформенный ключ следует отозвать и заменить.

## Как считается расстояние

Горизонтальное расстояние вычисляется на эллипсоиде WGS‑84 методом Винсенти. Это расстояние между GPS-точками, а не между объектами внутри изображения. Высота показана отдельно и не добавляется к горизонтальному расстоянию.

Точность результата физически ограничена точностью GPS в каждом снимке. Например, при точности ±5 м у обеих точек разница порядка нескольких метров может быть незначимой.

## Проверка

```powershell
node --test tests/core.test.js tests/ocr.integration.test.js
```

В тестах используются все семь предоставленных фотографий и проверяется реальное OCR-распознавание координат с подписей. У этих файлов числовые GPS-значения в EXIF обнулены, поэтому одного чтения метаданных недостаточно.

Готовый EXE также проверен сквозным тестом на пяти фотографиях `104565.jpg`–`104569.jpg`: распознаны все пять координат, общая длина маршрута в исходном порядке — около 570 м.

Для версии 1.4.0 отдельно проверен общий поиск по всему кадру на фотографии с неподписанной красной строкой: собранное приложение распознало точную пару `67.536477, 30.556022`, показало точку на встроенной карте и загрузило тайлы без раскрытия API-ключа в публичных URL.

Для версии 1.5.1 сквозной тест дополнительно проверяет пакетное распознавание семи фотографий с красной подписью в произвольной части кадра, а также нажимает внутри встроенной карты, проверяет появление произвольного маркера и расчёт расстояния и азимута от выбранной точки маршрута.

В версии 1.5.2 исправлено распознавание уменьшенных фотографий NoteCam: область подписи увеличивается и обрабатывается несколькими фильтрами, после чего приложение выбирает согласованный результат. На семи проблемных снимках размером 338×451 и 450×600 получено 7 точных пар из 7; повторная проверка семи исходных полноразмерных NoteCam-фотографий также дала 7 из 7.

В версии 1.5.3 усилена проверка цифр в полноразмерных подписях NoteCam. Приложение сравнивает результаты двух контрастных вариантов изображения, а при расхождении подключает дополнительные варианты и принимает координаты только после согласования. На новой контрольной серии из двадцати фотографий устранены четыре ошибки версии 1.5.2, включая потерю начальной цифры широты и подмену последних цифр; результат — 20 точных пар из 20.

В версии 1.5.4 добавлена полноценная поддержка PNG в Windows и Android: выбор файлов, перетаскивание, чтение стандартного PNG-блока `eXIf`, предпросмотр и локальный OCR. Если в PNG нет метаданных, приложение распознаёт подпись на изображении. Две полноразмерные контрольные фотографии, преобразованные из JPEG в PNG, распознаны точно до последней цифры.

В версии 1.5.5 добавлено отдельное быстрое распознавание верхней строки GPS Camera 55. Несколько независимых фильтров сверяют цифры между собой, после чего приложение при необходимости переходит к прежнему распознаванию нижней подписи NoteCam. Контрольная серия из 20 фотографий с верхней строкой и прежняя серия из 20 фотографий NoteCam распознаны полностью и точно до последней цифры. На серии GPS Camera 55 обработка ускорилась примерно в десять раз.

В версии 1.5.6 верхняя GPS-строка больше не обрезается справа, а резервный поиск сканирует весь кадр перекрывающимися полосами. Парсер восстанавливает десятичные точки, которые OCR прочитал как пробел, запятую, двоеточие, точку с запятой или дефис, и сверяет неоднозначные варианты с уже распознанными точками локального маршрута. Это устраняет зависимость от фиксированного положения подписи и не позволяет единичной ошибке первой цифры увести точку на сотни километров.

В версии 1.5.7 удалено исправление координат по соседним точкам маршрута: порядок и география других фотографий больше не могут подменить цифры текущего снимка. Нижняя подпись NoteCam читается с самого левого края и в расширенной области, а верхняя строка GPS Camera 55 подтверждается независимыми масками. На контрольных наборах точно распознаны 20 из 20 NoteCam, 15 из 15 смешанных фотографий и четыре сложных варианта GPS Camera 55.

Android-проект собирается командой `npm run build:android`. Для сборки нужны JDK 21, Android SDK Platform 36 и Android SDK Build Tools; готовый APK находится в `android/app/build/outputs/apk/debug/`.
